# Contributing to CodeBasir 🧠

Thank you for your interest in contributing to CodeBasir!

CodeBasir is an open-source project that helps developers understand programming errors through clear explanations and practical solutions.

Every contribution is welcome, whether it is code, documentation, testing, bug reports, or ideas.

## 🚀 How to Contribute

You can contribute by:

- Adding support for new error types
- Improving error explanations
- Adding practical examples
- Improving tests
- Fixing bugs
- Improving documentation
- Suggesting new features
- Adding support for new programming languages

## 🐛 Reporting Bugs

Before opening a new issue, please check whether the problem has already been reported.

When reporting a bug, include:

- A clear description of the problem
- The error message or input that caused the problem
- Expected behavior
- Actual behavior
- Steps to reproduce the issue

## 💡 Feature Requests

Feature ideas are welcome.

Please explain:

- What problem the feature would solve
- How the feature could work
- Why it would be useful for developers

## 🔧 Development Setup

Clone the repository:

```bash
git clone https://github.com/jmalkynj/codebasir.git
cd codebasir
```

Install the project:

```bash
python -m pip install -e .
```

Install the test dependency:

```bash
python -m pip install pytest
```

Run the tests:

```bash
python -m pytest
```

## 🧪 Testing

All changes should include appropriate tests when possible.

Before submitting a pull request, make sure:

```bash
python -m pytest
```

passes successfully.

GitHub Actions also runs the test suite automatically across supported Python versions.

## 📦 Pull Requests

Please keep pull requests focused on one change whenever possible.

A good pull request should:

- Explain what was changed
- Explain why the change was needed
- Include tests for new behavior
- Keep existing tests passing
- Update documentation when necessary

## 📝 Code Style

Please keep the code:

- Clear
- Simple
- Readable
- Consistent with the existing project structure

Avoid unnecessary complexity.

## 🌍 Language and Documentation

CodeBasir currently focuses on providing clear Arabic explanations for programming errors.

When adding or improving error definitions, please make sure the Arabic explanation is:

- Clear
- Accurate
- Easy to understand
- Practical for developers

## 🤝 Community

Please be respectful and constructive when communicating with other contributors.

Different ideas and approaches are welcome.
