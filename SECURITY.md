# Security Policy

## 🔐 Supported Versions

Security fixes are currently provided for the latest version of CodeBasir available on the `main` branch.

## 🚨 Reporting a Security Vulnerability

If you discover a security vulnerability in CodeBasir, please do not disclose it publicly through a GitHub issue.

Please report the vulnerability privately to the project maintainer.

Include as much of the following information as possible:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected file or component
- The potential impact
- A possible solution, if known

## ⏱️ Response

We will review security reports as soon as reasonably possible and work to understand, verify, and address valid security issues.

Please avoid publicly disclosing vulnerability details until the issue has been reviewed and a fix or mitigation is available.

## 🛡️ Security Scope

CodeBasir is currently an early-stage open-source developer tool focused on analyzing programming error messages.

As the project grows, its security policy and reporting process may be expanded to cover additional components, APIs, integrations, and supported programming languages.

## 📄 Responsible Disclosure

We appreciate responsible security research and coordinated disclosure.

Thank you for helping keep CodeBasir safe for developers and contributors.
